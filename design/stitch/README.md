# Zayna — Stitch UI export

Exported from Google Stitch. One folder per screen, each with a `code.html` (Tailwind via CDN).
The design system (colors, type, spacing, components) is in `warm_luxury_maghreb_heritage/DESIGN.md`.

| Folder | Screen |
|---|---|
| `accueil_zayna_jewelry` | Storefront home |
| `fiche_produit_collier_fatima` | Product page |
| `commander_paiement_livraison_cod` | COD checkout |
| `confirmation_de_commande_zayna_jewelry` | Order confirmation |
| `suivi_de_commande_zayna_jewelry` | Order tracking |
| `tableau_de_bord_espace_propri_taire_zayna` | Admin dashboard (desktop) |
| `espace_vendeur_tableau_de_bord` | Seller dashboard (mobile) |
| `gestion_des_commandes_zayna_admin` | Admin orders |
| `int_grations_transporteurs_zayna_admin` | Admin courier integrations |
| `grille_tarifaire_58_wilayas_zayna_admin` | Admin 58-wilaya shipping rates |

**Note:** Stitch's export failed to include the `screen.png` screenshots (each was a placeholder reading
"Image failed to fetch"), so they were left out. Open each `code.html` in a browser to see the screen.
All names, numbers and KPIs in the mockups are demo data.
